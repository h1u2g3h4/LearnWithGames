# Learn With Games

Math Quest is a browser-based math game for students in grades 4–6. Players solve questions, earn coins and XP, customize a character, and unlock rewards.

## Features

- Grade 4–6 math challenges
- Coins, XP, levels, and answer streaks
- Female and male characters with custom names
- Outfit, shoe, and accessory shop
- Saved progress using browser storage
- Responsive desktop and mobile design
- Future world slots for racing, flying, space, and building games

## Run locally

Open `index.html` directly in a browser, or start a small local server:

```powershell
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.
